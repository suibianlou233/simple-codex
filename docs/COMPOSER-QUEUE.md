# 底部输入框任务队列

运行时继续使用同一个 Composer 输入任务，Enter 入队，Shift+Enter 换行。等待项仅显示在输入框上方的紧凑列表，支持移除。Simple Code 仍可通过“立即补充”把当前输入追加到当前轮。模型和权限切换在运行时仍锁定。

队列使用既有 simple-code-queue:<taskId> 存储键，恢复旧队列时暂停，不自动补发。仅在当前任务页面保持打开、上一轮明确成功时逐条发送；失败、取消、发送回执不明会暂停。发送前持久化 inflight，未确认项需要用户核对后移除。

附件与长粘贴块沿用 Composer 的组装逻辑，一同冻结为队列消息；先持久化，再清空对应草稿。提交期间继续修改的草稿不会被较早的提交清空。界面不显示第二个顶部输入框或长期展开的发送记录。
