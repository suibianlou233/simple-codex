# Simple Code 与 Cursor 功能对照

核对日期：2026-09-16。开发基线为用户提供的 rc.2 ZIP；此目录独立于旧 simple-codex 工作区。

## 已实现的第一批

- 选区修改：选择文本，Ctrl/Command+K 或点击「AI 修改选区」，描述要求后生成差异。接受仅更新编辑器缓冲区，用户保存后才写磁盘。取消、截断响应、工具响应不允许应用；生成后内容变化或磁盘版本变化时拒绝旧建议。支持空替换删除、Unicode 和 CRLF。
- 文件引用：Simple Code 对话输入 @ 或点击引用按钮，搜索项目文件；优先读取已打开文件的缓冲区。标签显示路径、行范围、是否来自未保存内容。发送的是添加时的文本快照，可预览和删除；不是自动持续同步引用。
- 差异审查：编辑器「查看修改」高亮增删；「任务修改」分开显示最近一轮原生文件修改记录与 Git 工作区差异。命令修改可能没有原生 fileChange 补丁，不能把 Git 全部修改归因于 AI。任务补丁用于审查；选区建议支持逐块勾选接受，不恢复整仓快照。

## 内核与模型的边界

右侧多文件 Agent 任务仍使用固定 Codex 内核，未修改或重编译内核。
局部选区建议复用 Simple 已有模型适配层，使用界面当前模型进行一次无工具请求，要求结构化 replacement 输出。它没有文件写入能力、Shell 或任务历史；需要其他文件上下文时使用右侧 Agent。不同供应商对输出格式的遵循程度不同，格式错误时失败关闭，不能将不完整输出应用到文件。
文件路径检查、磁盘哈希和保存锁沿用桌面后端；密钥仍由后端凭据库读取，不传给前端。请求遵循模型配置的无数据超时，没有新增整个任务的固定完成时限。

## 第二批：编辑器工作流

- **草稿恢复**：版本化 IndexedDB 保存所有项目的编辑器缓冲、标签页、活动文件和光标行列；写入串行化，恢复失败不会静默覆盖。恢复后重新校验磁盘。关闭窗口可选择保留草稿退出或明确放弃。正常每次编辑立即发起异步持久化，崩溃前尚未提交的最后一次事务仍可能丢失。
- **文件同步**：Code 模式显示时每 1.5 秒检查根目录、展开目录和当前项目全部打开文件；窗口聚焦立即检查。外部创建/删除更新树；干净缓冲自动更新，有编辑则保留并展示冲突。文件删除保留内容、禁用覆盖保存。采用有界轮询，不是 OS 文件监听。
- **正文搜索**：后端检查项目边界、链接和敏感文件规则，搜索磁盘文本，返回 UTF-16 行列。限制前 10000 文件、32 MiB 扫描文本、300 条命中；达到上限明确提示。非文本/不可读/被禁止文件跳过；不扫描未保存缓冲。大小写不敏感针对 ASCII。
- **终端联动**：识别路径:行:列、TypeScript 路径(行,列)、Python File/line，含中文路径；点击在编辑器定位。选择报错后加入 AI 对话为待发送正文。相对路径按项目根目录解析；终端 cd 后相对子目录的路径仍需使用绝对路径。
- **逐块接受**：选区建议按连续差异切块，独立勾选接受/忽略，确认后一次性写入编辑缓冲；保留 CRLF/Unicode/尾换行，应用前重验缓冲和磁盘 SHA。已经落盘的 Codex 任务补丁不提供逐块撤销。
- **语义导航**：浏览器 Worker 中运行 TypeScript 语言服务，支持 JS/TS/JSX/TSX 的定义、引用与悬停类型；打开的未保存内容覆盖磁盘索引。最多 500 源文件/4 MiB；使用基础编译选项和 ES5/DOM 声明，尚未加载项目 tsconfig、路径别名、第三方依赖或其他语言 LSP。超限提示；索引缓存最多 3 秒。
- **讨论/计划/执行**：编辑区顶部三个入口；讨论和计划只接收当前文件与上一份答复，没有工具或文件写权限，结果保存在本机。计划加入右侧对话后作为可编辑正文参考，由用户发送才执行；不是 Codex 原生 collaborationMode。
- **AI 审查**：选择最近轮补丁或 Git 差异，点击 AI 审查。最多 20 条结构化缺陷，验证路径/行号后点击定位；差异变更时拒绝旧结果。未跟踪文件可能不在 Git 补丁内；审查不代表通过测试。
- **运行中指令**：运行时右侧出现独立输入区，立即追加使用固定内核 turn/steer 的 expectedTurnId 防止投错轮；排到下一轮只在前一轮成功、当前任务页面打开时顺序发送。队列按任务持久化，失败/取消/重启暂停；发送前先记 inflight，结果不确定绝不自动重试。切离页面暂停后台派发，回到页面需恢复；可删除未发送项并核对待确认项。模型/权限沿用主对话。

仍不提供 VS Code 插件兼容、完整调试器或整仓快照回滚。主 Agent 固定 Codex 内核无需重编译；辅助选区、讨论、计划、审查使用 Simple 模型适配器的无工具请求。

## 验证

2026-09-16：前端单元测试 175 项；Rust editor 相关测试 8 项和 steering 协议单元测试 1 项通过。
原生固定二进制通过 initialize + 无效 thread 的 turn/steer 探测，返回 thread not found，确认识别该协议且没有发起模型调用。
交互测试覆盖草稿重载/冲突、外部增删、实际 TS Worker 导航、计划转执行参考、审查跳转、逐块预览、队列顺序/失败/不确定响应重启以及原编辑器和窗口控件。最终 12 项 UI 回归全部通过，包含实际 TypeScript Worker 的引用导航。
测试使用本地模拟模型响应，不消费真实供应商接口；原生运行保留用户当前模型和项目配置。

## 极简编辑区（2026-09-16）

移除编辑区上方的模式工具栏、标签栏、重复路径和导航按钮行。多文件缓冲与草稿恢复继续保留；通过文件树或编辑器菜单切换文件。底部只显示当前路径、光标/未保存状态和「···」。右键、Ctrl/Command+Shift+P 或「···」打开操作菜单，支持方向键、Home/End、Esc、焦点恢复和窗口边界避让；保存、AI 修改选区、F12 与 Shift+F12 快捷键继续有效。讨论/计划/修改审查也从该菜单进入。菜单轻量过渡遵循 reduced-motion 设置。聊天气泡颜色保持不变。

菜单入口调整后的 9 项编辑器 UI 回归通过；已检查代码画面、菜单边界与键盘关闭。

## Simple / Simple Code 上下文隔离（2026-09-16）

新建会话以 contextMode=simple/code 持久化在原子的 task_backend_selected 事件中，任务投影返回归属；无字段的历史会话归 Simple，不删除或复制旧消息。分支继承源任务归属。界面按模式过滤会话列表、搜索、时间线、运行状态、差异与用量；每个项目/模式记住自己的当前会话与新对话状态，草稿键含模式。发送/模型配置期间禁止切换模式，避免异步提交落到另一上下文。

start_chat 带模式，start_turn 支持显式模式校验，跨模式发送在开始轮次前拒绝。Simple Code 使用独立的确定性 Codex history home（基于默认 home 和模式进行 SHA-256 分区），不迁入 Simple 线程或记忆；Simple 沿用原位置。代码与普通任务仍共同操作同一项目文件，模型配置与技能仍是共享设置，此功能不是文件系统隔离或允许同项目并行写入。

验证：176 项前端单元测试；10 项模式隔离与编辑器交互回归；桌面原有 131 项测试通过（16 项环境相关测试忽略），另有模式元数据重启、空新历史、独立 home 的后端测试。真实付费模型调用未用于回归。
