# Simple Code（本地开发预览）

顶部左侧选择 **Simple / Simple Code**。模式按项目记忆；切换只改变界面，不创建模型会话、不切换模型、不重启执行内核。Simple 保留对话布局；Simple Code 左侧是文件树，中间是编辑器，右侧为 AI / 终端 / 浏览器，分隔线可拖动。没有项目时使用“打开文件夹”。终端继续使用当前任务的真实 PTY。

## 第一版能力

- 按目录展开文件树；文件名搜索；创建文件/目录；通过文件行末的菜单重命名。名称以项目根目录为基准，父目录必须存在。
- 多标签文本编辑、行号、常见语言语法着色；Ctrl/⌘+F 查找与替换，Ctrl/⌘+S 保存；显示未保存标记。
- “文件加入对话”或“选区加入对话”把内容加入当前对话草稿，由用户点击发送。
- AI 回复中的项目内 Markdown 文件链接可打开编辑器；不把任意链接交给浏览器执行。
- “查看修改”在编辑区并排展示保存版本与当前内容，不生成项目快照，也不是 Git 变更审查器。

## 文件保护与边界

- 后端仅接收已打开项目的相对路径，拒绝越界路径、符号链接和 Windows reparse point。文件读取与保存复用现有 Workspace 文本/敏感路径限制（上限 1 MiB，UTF-8，不支持二进制编辑）。
- 保存、创建与重命名持有与 AI 相同的项目执行锁。AI 占用项目时，编辑器允许继续输入，写入操作可能暂时被拒绝；内容保留，任务结束后可重试。
- 保存使用读取时的 SHA-256 前提条件；磁盘已更新时拒绝覆盖。活动文件定时检查外部变化：干净文件自动加载，有未保存内容时展示冲突提示。用户可以比较并手动合并，或明确选择重新加载、放弃编辑；不自动解决冲突。
- 模式和项目切换保留内存中的缓冲区。关闭有未保存内容的标签、退出应用前有提示。尚未实现崩溃恢复、自动保存或重启后的草稿恢复。
- 复用 Workspace 的临时文件/备份替换流程，保留文件权限；不声称它能排除不遵守项目锁的外部程序在检查与替换之间产生的竞态。重命名同样只保证本应用及合作实例间的协调。
- 初版没有语言服务器、断点调试、自动重构、VS Code 插件兼容层或独立 Git 面板。没有修改固定的 Codex 内核；新增命令属于 Simple 本地控制面，继承仅 main webview 可调用的 IPC 边界。

## 验证

前端构建与类型检查、编辑器缓冲区/链接路径单元测试、Rust 文件保存冲突/路径/创建保护测试，以及浏览器中的模式切换、选区附件、外部变化冲突和原有对话界面回归。浏览器验收使用模拟文件，不调用用户模型。真实 PTY 与原生浏览器继续沿用原实现；此版本仍需 Windows/Mac 的实机使用反馈。
