# Simple 0.1.1-rc.2 — Simple Code 与中文任务进度

Windows x64 本地开发迭代版，程序内部版本仍为 0.1.1。

- 新增 Simple Code：项目目录、代码编辑与保存冲突提示，右侧 AI、交互终端和浏览器。
- 技能导入、查看、更新与启停；技能目录保存在用户本机。
- 执行记录紧凑分组折叠；合并重复窗口标题栏。
- 每次模型请求要求过程说明、恢复说明和最终回复使用简体中文；历史英文、代码及原始报错不改写。
- 保留图片拖拽/粘贴、视觉模型路由和可调宽右侧栏。

下载 Windows ZIP 后运行其中的 setup.exe，或直接下载安装器。需要 Windows 10/11 x64 和 WebView2。附对应源码 ZIP 与 SHA256 校验；不含开发者密钥、个人技能或聊天记录。

固定内核未重新编译。166 项前端测试、13 项模型网关测试通过；Windows 发布构建与安装包校验在上传前完成。干净机器安装与真实模型完整流程仍需用户验收，属于未签名测试版。

Mac 当前独立构建仍对应此前源码，完成后按既有流程发布到 v0.1.1-rc.1，不能视为本次 Windows 功能的等价包。
