# Simple 0.1.1-rc.1 — Images, browser and interactive terminal

## 中文

- 支持图片选择、粘贴、拖拽与预览；DeepSeek 带图请求自动路由视觉模型。
- 内置浏览器和真正的 PowerShell 交互终端统一放在右侧栏；左边框可拖拽调宽并保存宽度。
- 终端直接输入，支持 Ctrl+C，切换任务或浏览器保留会话；移除文件、Diff 面板入口。
- 发布版允许终端所需动态样式，内部版本升级为 0.1.1，固定内核未重新编译。

下载 ZIP 后运行其中的 setup.exe；另附 SHA256 校验文件。需要 Windows 10/11 x64 与 WebView2。本版为未签名测试版。

验证：150 项前端测试、生产构建、NSIS 打包、发布程序启动、内核与包内校验通过。图片/浏览器真实模型全流程及干净机器安装仍待验收；不代表全部功能或安全边界已完整验证。

此前 0.1.0 的安装包由本版替代，旧版本记录保留。

## English

Image selection, paste, drag/drop and previews are supported, with automatic DeepSeek vision routing for image requests. The embedded browser and a real interactive PowerShell terminal now share a resizable right sidebar. Terminal sessions survive task/browser switches; Files and Diff panel entries have been removed. The pinned kernel is unchanged.

Download the ZIP and run its setup executable. Windows 10/11 x64 and WebView2 are required. This is an unsigned prerelease.

Validation: 150 frontend tests, production build, NSIS packaging, release startup and integrity checks passed. Full image/browser model workflows and clean-machine installation still require acceptance. Older 0.1.0 installer assets are superseded by this release.
