# Simple 0.1.1 — Windows x64 分发测试版

发布标识：rc.20260910。程序内部版本为 0.1.1；这不是已经完整验收的稳定版。

## 安装与使用

1. 在 Windows 10/11 x64 上运行同目录的 setup.exe，按提示安装，然后从开始菜单打开 Simple。
2. 电脑需要预先安装 Microsoft Edge WebView2 Evergreen Runtime。安装包不自动联网下载运行时；若缺少，请先从微软官方渠道安装 WebView2 后重试。
3. 首次打开会显示“欢迎使用 Simple”。点击“开始配置”，填写自己的模型接口和 API Key，保存后打开项目，再发送任务。也可选择“稍后再说”；左下角“设置 → 查看使用引导”可再次查看。
4. 建议先发送一个不改文件的小任务，熟悉后再修改代码。重要项目请先备份或提交 Git，默认推荐使用需要审批的权限级别，检查操作后再批准。

已内置前端、Simple 本地控制层、固定 Codex 执行程序及其辅助程序。不需要下载 Rust、安装 C++ Build Tools、编译前端，或运行开发服务器。执行项目自己的 Git、Python、Node 等命令时，仍需安装该项目需要的工具。

本包没有数字签名，Windows 可能提示未知发布者。请先核对发布者提供的 SHA256 校验值；不要关闭系统安全防护。SHA256 可以核对文件完整性，但不能替代可信的数字签名。

## 数据与模型

安装包不包含开发者的 API Key、模型配置、聊天记录或项目内容。首次使用需要自行配置；模型请求按你配置的供应商计费。

本版使用官方候选内核的数据槽：
`%LOCALAPPDATA%\dev.localagent.desktop\kernel-slots\official-283-v1`。
同机器已有该槽时会继续使用；不会复制旧 slim 版本的任务历史。首次初始化时可能从该机器旧 Simple 配置中导入模型设置，密钥只在该机器的系统凭据存储中复制引用，不随本包转移。

本版固定使用随安装包携带的内核，忽略开发环境的内核选择变量；文件缺失或校验失败时拒绝启动，不静默回退旧内核。不要单独搬动安装目录里的主程序。更新/卸载前请关闭 Simple 并自行备份本地数据与项目。
