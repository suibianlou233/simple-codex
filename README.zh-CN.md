# Simple Codex

**一个基于固定版本 Codex 执行内核、开源且本地优先的 Windows 桌面 AI 编程助手。**

简体中文 · [English](README.md) · [下载 Windows 版本](https://github.com/suibianlou233/simple-codex/releases/download/v0.1.1-rc.1/Simple-0.1.1-rc.20260910-windows-x64-224336.zip) · [反馈问题](https://github.com/suibianlou233/simple-codex/issues)

非常感谢 OpenAI 开源了 Codex 的代码，让我有机会学习它的架构，并基于这些开源成果继续开发 Simple Codex。

Simple Codex 在 Codex 执行内核外，提供桌面界面、本地控制层和模型 API 适配层。打开一个项目，用自然语言描述任务，就可以让 AI 阅读代码、提出或实施修改，并在你选择的权限范围内执行命令。当前 Windows 版本使用 Simple 模型网关接入 DeepSeek；源码也包含通义千问和 OpenAI 兼容接口适配，具体兼容情况取决于模型与接口。

> **这只是一个非常初始的版本。** 项目仍在持续开发，可能存在错误、未完成的功能或不符合预期的行为。如果你愿意尝试，遇到问题还请见谅，也欢迎提供可以复现的反馈。我会持续开发和改进。让 AI 修改重要项目之前，请先做好备份。

## 下载与开始使用

1. 下载 [0.1.1 Windows 安装包 ZIP](https://github.com/suibianlou233/simple-codex/releases/download/v0.1.1-rc.1/Simple-0.1.1-rc.20260910-windows-x64-224336.zip)，不要下载 GitHub 自动生成的源码压缩包。
2. 解压后运行安装程序。需要 Windows 10/11 x64，以及已安装的 Microsoft Edge WebView2 Evergreen Runtime；安装包不会自动下载 WebView2。
3. 启动 Simple，首次使用引导会带你进入模型设置。填写接口地址、模型名称和 API Key，保存即可。
4. 点击左侧“打开项目”，选择本地文件夹。建议从一个小型只读任务开始，先使用需要审批的权限级别。

可以先发送：

```text
请阅读这个项目，告诉我应该如何启动。先不要修改文件，也不要执行命令。
```

以后可以通过 **设置 → 查看使用引导** 再次打开说明。当前软件界面主要为简体中文，README 提供中文和英文两版。

安装包已包含前端、本地后端、固定内核与辅助程序，普通用户不需要下载 Rust、安装 C++ Build Tools 或编译前端。但执行你自己项目的命令时，仍需要该项目依赖的 Git、Node.js、Python 等工具。当前安装包未签名，请核对 SHA256，并保留正常的系统安全防护。

## 当前具备的能力

- **桌面开发流程**：打开本地项目、管理对话、流式回复、停止生成、搜索任务及保存会话历史。
- **代码与命令工具**：通过内核和 Simple 权限控制读取项目、修改文件、执行终端命令。
- **右侧工作区**：内置浏览器和真实交互终端，拖动左边框调宽；文件与 Diff 面板入口已移除。完成后的过程说明折叠在“执行过程”中，后面显示本轮用时，最终回答单独保留。
- **模型配置**：包含 DeepSeek、通义千问和 OpenAI 兼容 API 适配，模型密钥保存在操作系统凭据库中。
- **本地控制**：本地任务数据与诊断记录、审批执行，以及明确记录限制的 Windows 沙箱集成。
- **分离式架构**：固定 Codex 内核与 Simple 兼容层分开管理，必要的上游修改保留来源、补丁和校验记录。

这里列出的是已实现的方向，不代表所有模型、任务和安全边界都已经完整验收。

## 本地优先，不等于模型离线运行

项目、任务记录和配置默认保存在你的电脑上。使用远程模型 API 时，提示词以及完成任务所需的项目内容、工具上下文会发送到你配置的接口，仍适用供应商的费用和隐私政策。

下载包不包含开发者的 API Key、模型配置、聊天记录或项目文件。反馈问题时，也请不要上传密钥或私人项目内容。

## 架构与内核升级

Simple 负责桌面界面、本地存储、模型网关、凭据管理及兼容适配。当前分发的 Codex 内核固定在提交 [`28327355`](https://github.com/openai/codex/tree/28327355b861ab6cc76b01c7248663eb1be440cf)。

我们的目标是让上游升级更容易维护，尽量不把产品兼容逻辑混入上游源码。**目前还不能任意版本直接热插拔。** 新版本仍需适配审查、版本包校验和行为验证，不能在任务运行中随意更换内核。

详情见 [开发说明](docs/DEVELOPMENT.md)、[内核版本清单](kernels/packages/official-283-windows-candidate-1/kernel.json) 和 [补丁记录](kernels/packages/official-283-windows-candidate-1/PATCHES.json)。

## 已知限制

- 当前 Windows 内核还不是旧定制内核的完整等价替代。
- 自动长期记忆、遗忘管理尚未迁移；多代理完整流程与完整沙箱边界还没有全部验收。
- 同一任务更换模型后，目前需要重启 Simple。
- Windows 复合命令可能出现中间步骤失败、最终退出码却为成功，需要检查实际结果。
- 已登记的 Windows V8 补丁关闭了 V8 内部沙箱。这与操作系统命令沙箱不是一回事，不能把当前程序当成经过完整安全验收的隔离环境。
- Git 工作区差异不等于精确的“最近一轮改动”。没有全项目快照式撤销，回退对话也不会自动撤销文件修改。
- 已知设置问题：能力读取失败时，可能连带隐藏本地记忆面板。

## 常见问题

### 这是用 DeepSeek 驱动 Codex 开源内核的桌面编程工具吗？

是的。Simple 在固定 Codex 内核外提供桌面界面与本地模型网关，DeepSeek 是当前开发使用的模型集成。这不代表支持全部 Codex 功能，也不代表所有 DeepSeek 接口都已兼容。

### 可以从源码继续开发吗？

可以。前端使用 React 和 TypeScript，桌面后端使用 Rust 和 Tauri。见 [开发说明](docs/DEVELOPMENT.md)。已编译的内核程序与 Git 源码历史分开分发。

### 遇到问题如何反馈？

欢迎在 [Issues](https://github.com/suibianlou233/simple-codex/issues) 中提供 Simple 版本、Windows 版本、复现步骤、预期结果和实际表现。发送日志或截图前，请去掉密钥、私人路径、对话内容和私有源码。
